Türkçe

PH Merkez, bir YouTube kanalının sahibinin kendi bilgisayarında çalışan kişisel bir araçtır. Bu sayfa, aracın Google kullanıcı verilerine nasıl eriştiğini, bunları nasıl kullandığını, sakladığını ve paylaştığını anlatır.

Erişilen veriler

  • YouTube Analytics ve YouTube Reporting API (izin yt-analytics.readonly, yalnız okuma): video başına günlük izlenme, ortalama izlenme süresi ve yüzdesi, kazanılan abone, gösterim ve gösterimlerin tıklama oranı.
  • YouTube Data API (izin youtube.force-ssl): kanal açıklaması ve anahtar kelimeleri (okuma; sahibinin onayıyla güncelleme), video yükleme ve zamanlama, video kapağı.

Araç yalnız izni veren hesabın kendi kanalına erişir; başka kişilerin verisine erişmez.

Kullanım

Veriler yalnız kanal sahibinin kendi kanalını ölçmesi ve yönetmesi için kullanılır: hangi başlığın ve kapağın daha çok tıklandığını görmek, kanal metnini güncellemek, hazırlanan videoyu yayına almak.

Saklama ve güvenlik

Veriler ve Google yetki anahtarları yalnız kanal sahibinin bilgisayarında saklanır; bir sunucuya gönderilmez. Yetki anahtarları ekrana ya da günlük dosyalarına yazılmaz. Google'a yapılan istekler şifreli bağlantıyla yalnız Google adreslerine gider.

Paylaşım

Google kullanıcı verileri satılmaz, reklam için kullanılmaz ve üçüncü kişilerle paylaşılmaz. Kanal sahibi, kendi kanalı hakkında öneri almak için bu sayıların özetini kendi kullandığı yapay zekâ asistanlarına verebilir. PH Merkez bu verileri yapay zekâ modellerini eğitmek için kullanmaz.

Google API Hizmetleri Kullanıcı Verileri Politikası

PH Merkez'in Google API'lerinden aldığı bilgileri kullanması ve başka bir uygulamaya aktarması, Sınırlı Kullanım şartları dahil Google API Hizmetleri Kullanıcı Verileri Politikası'na uyar.

YouTube API Hizmetleri

PH Merkez, YouTube API Hizmetlerini kullanır. Aracı kullanan kişi YouTube Hizmet Şartları'nı kabul etmiş olur. Google'ın verileri nasıl işlediği Google Gizlilik Politikası'nda anlatılır.

İzni geri alma ve silme

Verilen izin her an Google hesabının güvenlik ayarlarından geri alınabilir: myaccount.google.com/permissions. İzin geri alınınca araç kanala erişemez; bilgisayardaki kayıtlar sahibinin isteğiyle silinir.

Değişiklikler ve iletişim

Politika değişirse bu sayfa güncellenir. Sorular için: github.com/EmreUYGUNX/ph-merkez-uygulama.

English

PH Merkez is a personal tool that runs on the computer of a YouTube channel owner. This page explains how the tool accesses, uses, stores and shares Google user data.

Data accessed

  • YouTube Analytics API and YouTube Reporting API (scope yt-analytics.readonly, read-only): daily views per video, average view duration and percentage, subscribers gained, impressions and impressions click-through rate.
  • YouTube Data API (scope youtube.force-ssl): channel description and keywords (read; updated with the owner's approval), video upload and scheduling, video thumbnail.

The tool only accesses the channel of the account that grants permission; it does not access anyone else's data.

How the data is used

The data is used only so that the channel owner can measure and manage their own channel: seeing which titles and thumbnails get more clicks, updating the channel text and publishing prepared videos.

Storage and security

Data and Google authorization tokens are stored only on the channel owner's computer and are not sent to any server. Tokens are never shown on screen or written to log files. Requests to Google go only to Google addresses over encrypted connections.

Sharing

Google user data is not sold, not used for advertising and not shared with third parties. The channel owner may give a summary of these numbers to AI assistants they use, to get suggestions about their own channel. PH Merkez does not use this data to train AI models.

Google API Services User Data Policy

PH Merkez's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

PH Merkez uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. How Google handles data is described in the Google Privacy Policy.

Revoking access and deletion

Access can be revoked at any time from the Google Account security settings: myaccount.google.com/permissions. After revocation the tool can no longer access the channel; records on the computer are deleted at the owner's request.

Changes and contact

If this policy changes, this page will be updated. Questions: github.com/EmreUYGUNX/ph-merkez-uygulama.
